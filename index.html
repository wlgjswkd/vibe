01 · 왜 어려울까?

예전에는 코드 문법부터 배웠어.

우리가 떠올린 생각
“버튼을 누르면
점수가 1점 올라가게 해줘!”

우리가 원하는 건 작동하는 기능이야.

직접 코딩하는 예시
let score = 0;
button.onclick = () => {
  score = score + 1;
  display.textContent = score;
};

컴퓨터가 이해할 코드의 규칙을 알아야 해.

직접 코딩도 중요하지만, 오늘은 AI의 도움을 받아 시작해 볼 거야.

02 · 바이브 코딩의 뜻

원하는 느낌을 설명해 봐!

바이브(Vibe)는 분위기나 느낌이라는 뜻.
사람이 원하는 기능·분위기를 말하면 AI가 코드를 만드는 방식이야.

1

내가 설명한다

“30초 동안 표적을 누르는 게임을 만들어 줘.”

➜
2

AI가 코드를 만든다

HTML·CSS·JavaScript 코드로 기능을 구현해.

➜
3

실행하고 고친다

직접 눌러 보고 부족한 점을 다시 설명해.

핵심! AI는 한 번에 완벽하지 않을 수도 있어. 사람이 직접 실행하고 확인해야 해.
03 · 우리가 즐기는 디지털 세상

요즘 우리는 이런 걸 즐기지?

🎬

영상

영상 편집 도구, 자막 생성기, 영상 소개 페이지

🎵

음악

나만의 플레이리스트, 박자 맞추기 게임

🎮

게임

반응속도 테스트, 에임 훈련, 두더지 잡기

오늘은 복잡한 설치가 필요 없는 웹 게임(HTML)부터 만들어 보자!

04 · AI에게 부탁하는 방법

프롬프트는 제작 설명서야.

AI에게 입력하는 요청 문장을 프롬프트(Prompt)라고 해.

① 종류

무엇을?

“반응속도 게임을”

② 규칙

어떻게?

“초록색이 되면 클릭”

③ 숫자

얼마나?

“5회, 평균과 최고기록”

④ 화면·환경

어떤 모습?

“큰 버튼, 스마트폰에서도”

결과물 형식도 알려주자. “HTML 파일 하나로 만들어 줘.”
05 · 좋은 프롬프트 만드는 법

짧더라도 구체적으로!

🙅 아쉬운 프롬프트
“재밌고 멋진 게임 하나 만들어 줘.”

어떤 게임인지, 어떻게 하는지 알기 어려워.

🙆 좋은 프롬프트
“30초 동안 동그란 표적을 클릭하는 게임을 만들어 줘. 점수는 1점씩 오르고, 표적 크기는 80px로 해 줘.”

동작과 숫자가 있어 AI가 이해하기 쉬워.

✓하나의 문장에 모든 내용을 우겨넣기보다 문장을 끊어 설명하기
✓시간·횟수·크기·점수 등 숫자로 조건 표현하기
✓스마트폰과 크롬북에서도 작동해 달라고 요청하기
06 · 프롬프트로 조금씩 고치기

처음부터 완벽할 필요 없어.

큰 요청 한 번보다 만들기 → 실행 → 수정하기를 반복하자.

첫 요청
클릭하면 점수가 1점씩 올라가는 간단한 웹 게임을 만들어 줘. HTML 파일 하나로 작성해 줘.
첫 번째 수정
게임 시간을 30초로 제한하고, 남은 시간을 화면 위에 크게 표시해 줘.
두 번째 수정
스마트폰에서도 손가락으로 누를 수 있게 하고, 게임 종료 후 다시 시작 버튼을 만들어 줘.
07 · AI와 대화하는 요령

주제가 바뀌면 새 대화를 열자.

AI가 앞에서 만들던 내용을 계속 참고해서 새 요청을 엉뚱하게 해석할 수 있어.

🔧

같은 게임을 수정한다면?

기존 대화에서 계속!

“방금 만든 반응속도 게임에 평균 기록도 넣어 줘.”
🆕

전혀 다른 걸 만든다면?

새 대화를 시작!

“이제 가계부 프로그램을 새로 만들 거야.”
새 대화에서 기존 프로젝트를 이어야 한다면, 이전 코드와 필요한 조건을 다시 전달해 줘.
08 · 직접 체험 · 게임 예시 1

⚡ 반응속도 테스트 5회

AI에게 이렇게 부탁해 봐
웹브라우저에서 실행되는 반응속도 테스트 게임을 만들어 줘. 1. 시작하면 1.5~3.5초 뒤 화면이 초록색으로 바뀌어. 2. 초록색으로 바뀌는 순간 클릭하거나 터치하면 반응 시간을 밀리초(ms)로 기록해. 3. 총 5회 측정하고 최고기록과 평균기록을 보여 줘. 4. 너무 빨리 누르면 그 회차를 다시 측정하게 해 줘. 5. 스마트폰에서도 잘 작동하고, HTML 파일 하나로 만들어 줘.
반응속도는 숫자가 작을수록 빠른 거야. 1초 = 1,000ms
⚡ 반응속도 실험실0 / 5회
—최근 기록(ms)
—최고기록(ms)
—평균기록(ms)
준비되었나요?
시작 버튼을 눌러 주세요.
5번 도전해 보자!
09 · 직접 체험 · 게임 예시 2

🎯 에임(Aim) 훈련 30초

AI에게 이렇게 부탁해 봐
초보자도 할 수 있는 에임 훈련 게임을 만들어 줘. 1. 게임 시간은 30초야. 2. 화면 안에 지름 80px 정도의 동그란 표적이 한 개 나타나. 3. 표적을 누를 때마다 점수가 1점 올라가고 다른 위치에 새 표적이 나타나. 4. 빈 곳을 누르면 빗나간 횟수로 기록해. 5. 종료 후 맞힌 개수와 명중률을 보여 주고 다시 시작할 수 있게 해 줘. 6. 마우스와 스마트폰 터치 모두 지원하는 HTML 파일 하나로 만들어 줘.
명중률 = 맞힌 횟수 ÷ 전체 클릭 횟수 × 100 (%)
🎯 표적 맞히기일반인 난이도
30.0남은 시간(초)
0명중
—명중률(%)
준비되면 시작 버튼을 눌러 봐!
표적을 빠르게 눌러 보자!
10 · AI에게 수정 요청하기

이제 나만의 게임으로 바꿔 봐!

하나를 선택하고 바로 프롬프트를 복사해 보자.

🎨 디자인 변경
게임의 배경은 짙은 남색으로, 버튼은 밝은 민트색으로 바꿔 줘. 글씨는 지금보다 20% 크게 해 줘.
🔊 효과 넣기
표적을 맞히면 짧은 효과음이 나게 하고, 점수가 10점 올라갈 때마다 축하 메시지를 1초 동안 띄워 줘.
🏅 기록 비교
게임이 끝나면 이번 기록과 이전 최고기록을 비교해 줘. 브라우저에 최고기록을 저장해 새로고침해도 유지되게 해 줘.
📱 모바일 개선
휴대전화에서도 화면 밖으로 내용이 넘치지 않게 만들어 줘. 버튼은 손가락으로 누르기 편하게 최소 48px 높이로 해 줘.
11 · 완성하고 공유하기

내가 만든 게임을 친구에게!

1

저장하기

AI가 작성한 코드를 game.html로 저장해.

2

확인하기

크롬에서 파일을 열어 작동하는지 직접 테스트해.

3

공유하기

GitHub Pages 같은 웹 게시 서비스를 이용해 링크로 공유해.

주의! 내 컴퓨터 안의 파일 주소는 다른 친구가 바로 열 수 없어. 인터넷에 게시하거나 파일 자체를 전달해야 해.

링크를 QR 코드로 바꾸면 스마트폰으로도 간편하게 체험할 수 있어.
